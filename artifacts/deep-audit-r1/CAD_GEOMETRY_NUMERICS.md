## Invariants confirmed

* **Truth is authored, everything else derived.** A CAD body stores `CadSketch` (plane, entities with per-sketch ids, `nextEntityId`) + `ExtrudeFeature`; the closed profiles, polygon, triangles and mesh are regenerated by `generateCadMesh` — the ONE path. No rule reads a sketch parameter back out of a vertex (grep + read).
* **Arc = three authored points on the curve; Spline = its interpolated point list.** Centre/radius/sweep/handles/tessellated points come from `tessellateSketchCurve` and the bounds constants alone — never a camera, zoom or window. Confirmed: the semicircle fixture's derived circle is exact; collinear arc points are refused (`InvalidArc`); a far-from-origin triple is handled.
* **One chain walker** (`extractClosedProfiles`) chains lines, arcs and splines by coincident AUTHORED endpoints, so a denser tessellation cannot open or close a profile. A curve's extruded side face is NEVER eligible to support a sketch, decided per polygon edge (a profile may mix curves and exact lines).
* **Fail closed by name.** Open, forked, crossing, zero-area, duplicate-edge and nested loops are refused (`OpenProfile`, `BranchingChain`, `SelfIntersectingProfile`, `ZeroAreaProfile`, `DuplicateEdge`, `NestedProfileUnsupported`), never repaired. `applyState` validates the whole requested state and writes nothing unless all of it passes — no half-regenerated body.
* **Semantic faces.** `CadFaceToken` = kind + producing profile-edge entity; `cadTopologySignature` = FNV-1a 64 (basis `0xCBF29CE484222325`, prime `0x100000001B3`) over the profile anchor, the face count and each face's token code + eligibility — matching `DATA_PACKAGE_SPEC.md` §7c and the PowerShell builder (the parity that found the mistyped basis in CAD-A3-C1). A face reference resolves only when the producer exists, is a CAD body, its signature still matches and the named face is eligible; a stale lineage, missing producer, bad token, curved-circle side or cycle all fail closed. A face-supported body's world placement is derived (`resolveWorldModel = producerWorldModel · faceFrame`) and it is not independently transformable.
* **Edit Sketch** is staged (`beginEdit` copies), `commitEdit` is one `ScopedConstructionEdit` (one Undo), and an edit that would strip a face a dependent stands on is refused `DependentFaceLost` — verified `CADUXR1_32..36`.
* **`applyLineLength`**: P0 fixed, direction unchanged, `P1' = P0 + normalize(P1−P0)·length`; zero/negative/non-finite/out-of-range refused, never clamped; an opened chain is reported at `finish`, never repaired (`CADUXR1_20..24`).
* **View ≠ plane.** `viewFlipped`/`viewQuarterTurns` are presentation only, never persisted/fingerprinted; `viewFrame` is always right-handed, so no view state can mirror a sketch (`CADUXR1_08..13`).

## Numerics

* Bounds enforced: 256 entities, 256 polyline verts, 32 spline pts, 1024 profile verts.
* Ear-clipping `triangulateSimplePolygon`: `isEar` is O(n) → O(n³) worst case at n ≤ 1024. Nested-profile containment is O(P²·n·m). Both bounded; a hostile CADB file can cost ~1 s at load (F-09, P2 — `PERFORMANCE_MEMORY.md`). No correctness issue.
* The arc's circumscribed circle uses a determinant solve with a collinearity guard; the spline is Catmull-Rom → Bézier, tessellated by a bounded segment count. Every geometry comparison on a product path uses a tolerance, not exact equality (exact equality appears only in determinism self-tests).
* Performance (device print): `FORGESHAPE_CAD_PERFORMANCE` rectangle extract 32 µs / triangulate 18.5 µs / regen 17.1 µs; polyline128 extract 359 µs / triangulate 184 µs / regen 754 µs. `FORGESHAPE_SKETCH_UX_PERFORMANCE` arc_tess 4.2 µs, spline_tess 2.1 µs, curve_profile 23 µs, curve_regen 51 µs (per unit). All far below a frame.
